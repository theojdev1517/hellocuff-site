# HelloCuff coming soon

A simple static introduction to HelloCuff, a business card for your wrist.

Open `index.html` or serve this directory with any static web server. No build step, dependencies, analytics, or form service is required.

Current color trial: navy `#142D55`, cobalt `#275EFE`, sky `#B9DEFF`, ice `#F4F8FF`. Original evergreen/cream/lime direction remains in Git history.

Typography trial: Outfit for the text wordmark, headings and body. Unmodified font files and their licenses are in `fonts/`. Open `font-preview.html` to compare Outfit, Plus Jakarta Sans and Space Grotesk.

The page uses a live text wordmark while the selected speech-bubble logo concept is developed. The typography and blue colors are trials requested for comparison.
