# HelloCuff font files

Downloaded October 19, 2026 from the official [Google Fonts repository](https://github.com/google/fonts). These are the unmodified upright variable TTF fonts; the matching SIL Open Font License is included for each family.

| Family | File | Official source |
|---|---|---|
| Outfit | `outfit-variable.ttf` | [google/fonts: Outfit](https://github.com/google/fonts/tree/main/ofl/outfit) |
| Plus Jakarta Sans | `plusjakartasans-variable.ttf` | [google/fonts: Plus Jakarta Sans](https://github.com/google/fonts/tree/main/ofl/plusjakartasans) |
| Space Grotesk | `spacegrotesk-variable.ttf` | [google/fonts: Space Grotesk](https://github.com/google/fonts/tree/main/ofl/spacegrotesk) |

The landing page uses Outfit. `font-preview.html` displays all three. Font files are served from this site; no Google Fonts runtime request is required. Preserve each `*-OFL.txt` file when redistributing the font files.
